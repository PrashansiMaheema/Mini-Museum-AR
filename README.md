# Mini Museum AR Exhibition

## Project Description
This project is an Augmented Reality Mini Museum created using A-Frame and AR.js.

## Features
- Rotating torus
- Moving sphere
- Rotating cube
- Cylinder
- 3D avocado model
- Colour-changing sphere interaction
- Growing and shrinking cube interaction
- Hiro marker detection status banner

## Technologies Used
- HTML
- A-Frame
- AR.js
- JavaScript
- glTF / GLB 3D model
